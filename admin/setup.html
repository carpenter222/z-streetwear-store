إعداد لوحة الإدارة

الصفحة دي لصاحب حساب GitHub بس، وبتتعمل مرة واحدة. بعدها صاحب المحل يدخل اللوحة باسم مستخدم وكلمة سر بس.

١. حساب GitHub

إزاي أعمل المفتاح؟
  1. افتح صفحة عمل مفتاح جديد على GitHub.
  2. Token name: اكتب أي اسم، مثلاً Z admin.
  3. Expiration: اختار أطول مدة متاحة.
  4. Repository access: اختار Only select repositories، واختار repository المتجر بس.
  5. Permissions ← Repository permissions ← Contents: اختار Read and write.
  6. دوس Generate token، وانسخ المفتاح وحطه هنا.

٢. بيانات دخول صاحب المحل

استخدم كلمة سر طويلة ومش سهلة تتخمّن، زي ٣ أو ٤ كلمات ورا بعض مع أرقام. كلمة السر دي هي اللي بتحمي مفتاح GitHub.
